# Objetivos del proyecto

Crear un MVP de venta de articulos catolicos llamado "El Taller De Maria". usando NextJS, MongoDB y Tailwind.

El proyecto ya esta creado y con tailwind instalado, pero sin estilos ni funcionalidades. l objetivo es implementar el diseño y las funcionalidades básicas para un E-Commerce pequeño. para luego ir agredando funcionalidades y escalando el proyecto, siguiendo exactamente los diseño presentados en las referencias que seran proporcionadas en la carpeta "antigravity" dentro del proyecto
